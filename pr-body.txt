Getting Started

1. Clone & Install
   git clone https://github.com/orbitwebsites-cloud/true-adam-os
   npm install

2. Add Free API Key (pick one)
   - Groq (fastest): https://console.groq.com → copy API key
   - Cerebras: https://www.cerebras.ai/api
   - Together: https://www.together.ai
   - OpenRouter: https://openrouter.ai

3. Create `.env.local`
   GROQ_API_KEY=gsk_xxxxx
   # or CEREBRAS_API_KEY, TOGETHER_API_KEY, etc

4. Run Locally
   npm run dev
   # Visit http://localhost:3000

5. Deploy to Vercel
   npm i -g vercel
   vercel
   # Add API key in dashboard
   vercel --prod
